# i18n and RTL / LTR

The site uses `i18next` and `react-i18next`.

## Files

Translation JSON files live under:

- `src/assets/locales/ar/`
- `src/assets/locales/en/`

Namespaces:

- `common`
- `home`
- `about`
- `deanMessage`
- `departments`
- `programs`
- `news`
- `announcements`
- `faculty`
- `services`
- `events`
- `contact`

They are registered in `src/i18n.js`.

## Language switcher

The header button switches between Arabic and English. On change it:

1. Calls `i18n.changeLanguage(lang)`
2. Sets `document.documentElement.lang`
3. Sets `document.documentElement.dir` to `rtl` for Arabic and `ltr` for English
4. Saves the choice in `localStorage` under `lang`

On load, `App.jsx` reads that value and restores the language and direction.

## Usage in components

```jsx
const { t } = useTranslation('faculty');
t('page.title');
```

UI text should come from translation keys so both languages stay in sync.
