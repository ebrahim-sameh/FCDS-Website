# Submission checklist

TechTrek submission deadline: 13/8/2026. Discussion: 13/8/2026, 6:00 PM.

Form: https://docs.google.com/forms/d/e/1FAIpQLSfXaOVaBSizucM-rBs0T8vPaIRkabEOJtHKPqHlSsVgE2FUlw/viewform

## ZIP contents

Name the ZIP like `Team_XX_React.zip` (use your real team number).

Include:

1. Source code (this repo without `node_modules` and without `dist`)
2. Project presentation (`docs/presentation.md`, or export to slides)
3. README (`README.md`)
4. Run screenshots (`docs/screenshots/`)
5. Short project video (record 1 to 2 minutes of the site running; the team must record this)
6. Optional: production build notes from `npm run build`

## Before you upload

```bash
npm install
npm run build
npm run preview
```

Check Arabic and English. Open a few routes from the README Routes list. Confirm the contact form shows validation errors when empty.

## Team fields for the form

Fill in team number, member names, track, and project name in the Google Form when one member uploads the ZIP.
